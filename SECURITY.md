# Security Policy

Do not open a public issue containing credentials, private keys, real internal addresses, hostnames, logs with personal data, or unredacted configuration.

If sensitive data is found in the repository, rotate the affected credential first, then remove it from the current tree and history. Assume a committed secret is compromised even if it was deleted quickly.

Examples in this repository use RFC 5737 documentation addresses, `.invalid` hostnames, dummy account names, and `.example` configuration files.

# Roadmap

## v0.1 — Inventory baseline

Create a sanitized inventory, evidence-gap list, architecture overview, and safe read-only collection process.

## v0.2 — Access, users, and permissions

Document users, groups, sudo, ACLs, service accounts, SSH keys, and Docker-equivalent privilege.

## v0.3 — SSH, firewall, and exposure

Verify effective SSH policy, IPv4/IPv6 exposure, and active Netfilter behavior before proposing changes.

## v0.4 — Patch and maintenance strategy

Define repository policy, security-update cadence, maintenance windows, reboots, validation, and rollback.

## v0.5 — Backup foundation

Define protected data, backup target, encryption, retention, RPO/RTO, monitoring, and failure handling.

## v0.6 — Restore and disaster recovery

Perform file, configuration, service, and rebuild-oriented restore exercises with evidence.

## v0.7 — systemd, logging, and monitoring

Create isolated test services and timers; document journal retention and host-level monitoring.

## v0.8 — Troubleshooting lab

Implement reproducible, reversible failure scenarios and document the complete diagnostic path.

## v0.9 — Shell automation and tests

Add safe inventory, diagnostics, and validation scripts with static and integration tests.

## v0.10 — Ansible baseline

Automate only the procedures already understood, executed manually, tested, and documented.

## v1.0 — Reproducible Linux operations baseline

Publish an end-to-end Debian operations, security, troubleshooting, backup, restore, and recovery portfolio.
